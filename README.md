## 🚀 Projeto em destaque

### Atenas Documentos
Sistema web em produção para a **Atenas Projetos Ambientais**, consultoria que faz documentos técnicos para hospitais, clínicas e farmácias. Transforma horas de trabalho repetitivo em poucos cliques.

- **POPs:** a partir de modelos `.docx`, gera capa, cabeçalho em todas as páginas e troca os dados da empresa no texto inteiro
- **PGRSS:** formulário que gera o Plano de Gerenciamento de Resíduos completo; a busca pelo CNPJ preenche endereço e atividades da Receita
- Edição de `.docx` direto no XML (Open XML), sem bibliotecas externas
- Login com três níveis de acesso, senhas criptografadas, bloqueio por tentativas e HTTPS
- Publicado em hospedagem compartilhada (cPanel), com SSL e histórico de atividades

**Tecnologias:** PHP 8 · SQLite / MySQL · HTML · CSS · JavaScript · Open XML
🌐 [atenasprojetosambientais.com.br](https://atenasprojetosambientais.com.br) · *código privado (projeto de cliente)*
