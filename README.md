## 🚀 Projeto em destaque

### Atenas Documentos
Sistema web feito para a **Atenas Projetos Ambientais**. Ele personaliza os POPs (Procedimentos Operacionais Padrão) da empresa: a partir de um modelo `.docx`, gera automaticamente capa, sumário, cabeçalho, rodapé e os dados de cada cliente.

- Login com três níveis de acesso e aprovação de novos funcionários
- Geração de documentos Word direto pelo navegador
- No ar, com hospedagem própria e HTTPS

**Tecnologias:** PHP 8 · SQLite / MySQL · HTML · CSS · JavaScript
🌐 [atenasprojetosambientais.com.br](https://atenasprojetosambientais.com.br) · *código privado (projeto de cliente)*
